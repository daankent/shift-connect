# ShiftConnect

ShiftConnect is an application where supermarket managers can post open shifts they have at their store they are unable to fill with their own team. Employees from other store can then register to work these shifts.

[Frontend](./frontend/README.md)
[Backend](./backend/README.md)

## Features

Features **in the MVP** include:

- [ ] Users can login to the application
- [ ] Managers are able to post open shifts (including basic info about the shift such as required skills)
- [ ] Employees can find shifts using filters
- [ ] Employees are able to register for open shifts (if they have the required skills)
- [ ] Managers are able to accept or decline the registrations of employees
- [ ] Employees can see the shifts they are accepted for and get information on travel

Features that can be added **after the MVP** include:

- [ ] Notifications when new actions take place (like registering, accepting/declining registrations etc)
- [ ] Reporting no-shows so that managers from other shops can see how reliable an employee is
- [ ] Enabling employees to adjust the shift times when registering if this suits them better
- [ ] Requiring the manger of the employee that register for a shift to confirm they are able to do the task the open shift is for
- More ideas....
